使用者回報 IGDB 搜尋帶入的結果沒有顯示平台，另外詢問輸入中文/日文會不會自動翻譯成英文再查 IGDB。

**平台沒顯示的根本原因**：查了 GAS 後端的 `igdbProxy()` 實作，發現後端其實早就把 IGDB 原始 API 回應拆解整理成扁平物件回傳（`platform` 直接是字串、`release_date` 已格式化成 `YYYY/MM/DD`、還額外準備了 `meta` 欄位專門給顯示用，格式就是「平台 · 年份」）。但前端 `extractField()` 的 IGDB 對照表當初是照 IGDB 原始 API 那種巢狀結構寫的（例如 `data.platforms[0].name`、UNIX 時間戳記的 `data.first_release_date`），欄位名稱完全對不上後端實際回傳的扁平格式，導致平台/開發商/發行商/發售日/類型這幾個欄位一直悄悄抓空。**這個問題不只影響這次新增的搜尋功能**——原本就有的跨源自動比對（`crossRefLookupPromise`）用到 IGDB 的部分，也是呼叫同一個後端動作、吃同一份錯誤對照表，只是那邊有其他資料源可以互相補位，沒有這麼明顯。
