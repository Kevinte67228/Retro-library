**根因**：`showPg()` 判斷「要不要用快取、還是重新連網」的邏輯是 `cached && cached.length`。當收藏或尋寶清單真的是 0 筆時，成功同步後快取存的是空陣列 `[]`——但 `[].length` 是 0（falsy），導致這個判斷式把「已經成功同步過、確認是 0 筆」的快取，跟「從來沒快取過」的狀況判斷成同一種情況，兩者都會觸發重新連網。結果就是只要收藏或尋寶是空的，**每次切換到這兩個分頁都會重新打一次網路請求、跳一次載入圈**，快速來回切換就會看起來像不停載入。

**修復**：改用 `Array.isArray(cached)` 判斷——只要曾經成功快取過（即使是空陣列），就直接顯示空狀態，不用再自動連網。收藏、尋寶兩處都已修正。
