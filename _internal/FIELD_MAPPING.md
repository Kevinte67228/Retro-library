# RetroVault 欄位對照表（Google 試算表欄位 ↔ App 顯示名稱）

這份文件列出目前所有分類/子類型用到的欄位，每個欄位的 **id** 就是 Google 試算表的欄位名稱（標題列文字），
也是 GAS 後端與前端 JS 資料物件裡的 key；**顯示名稱** 是 App 畫面上實際看到的中文標籤。

⚠️ **同一個欄位 id 在不同分類/子類型下，顯示名稱、所屬分組可能不同**（例如 `release_date` 在遊戲類顯示
「發售日期」，在攻略類顯示「出版日期」）——這是欄位共用機制的設計（不同分類重用同一個底層欄位存資料，
只是呈現給使用者的標籤依語境調整），不是資料錯誤。下表把同一個 id 底下看過的所有變體都列出來。

此文件由程式碼自動掃描產生（掃描 `docs/index.html` 裡的欄位定義），如果之後新增/修改欄位，
重新執行同一套掃描腳本即可更新，不需要手動維護（腳本存放在 `_internal/gen_field_mapping.py`）。
